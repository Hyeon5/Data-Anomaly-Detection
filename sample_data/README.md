# 샘플 데이터 안내

모든 샘플은 **CSV / XLSX 두 형식(동일 데이터)** 으로 제공되어, 두 업로드 방식을 모두 검증하실 수 있습니다.
각 샘플은 해당 기능만 켜고 실행하시면 결과를 가장 명확하게 확인하실 수 있습니다.

## 개별 기능 테스트용 (9종)

| 파일 | 확인할 기능 | 기대 결과 |
|------|------------|-----------|
| `sample_01_결측치` | 결측치 탐지 | 3·7·11·15·18행에서 결측(빈 값/공백/NULL) 탐지 (총 5행) |
| `sample_02_이상치` | 이상치 탐지 (IQR/Z-Score/ML) | 10·20·30·40행의 극단값 탐지 — IQR만 켜면 정확히 4행 |
| `sample_03_중복데이터` | 중복 데이터 탐지 | 6=7행, 15=16=17행 완전 중복 (총 5행) |
| `sample_04_타입추론` | 데이터 타입 자동 추론 | 정수·실수→Number, 날짜 2형식→Date, 불리언·문자열·숫자문자혼합→String |
| `sample_05_품질점수` | 데이터 품질 종합 점검 | 결측 3건 + 중복 1쌍 + 나이 250/구매금액 950만 이상치 동시 탐지 |
| `sample_06_기술통계` | 기술통계(최소/최대 등) | 숫자 컬럼 설정 표에서 국어/수학/영어의 실제 최소·최대 확인 |
| `sample_07_상관관계` | 상관관계(다변량) | 광고비↑→매출↑(양의 상관), 반품비용↓(음의 상관) — Isolation Forest 로 복합 이상 확인 |
| `sample_08_분포분석` | 분포별 탐지 차이 | 치우친 분포에서 IQR 과 Z-Score 의 탐지 개수가 서로 다름 |
| `sample_09_파라미터테스트` | 알고리즘 파라미터 반영 | Z-Score 2.5→3행 / 3.0→2행, 증감률 50%→3건 / 100%→2건 / 200%→1건 |

### 두 파일 비교 검증 사용법

1. [두 파일 비교 검증] 탭에서 **A = 종합1(2023)**, **B = 종합2(2024)** 를 올려 주세요. (CSV↔XLSX 교차 가능)
2. 기준 컬럼이 `관리번호 ↔ 관리번호` 로 자동 추천됩니다.
   (컬럼명이 다른 `산단명 ↔ 산업단지명` 도 자동으로 짝지어 비교됩니다)
3. [비교 시작] 을 누르면 아래 결과를 확인하실 수 있습니다.

| 항목 | 기대 결과 |
|------|-----------|
| 총 비교 행 | 35 |
| 동일 / 변경 | 16 / 11 |
| 추가 / 삭제 | 4 / 4 (GJ-1031~34 추가, GJ-1003·1011·1027 삭제 + 중복키 1) |
| 이상 변동 | 4행 — 매출액 +50% / +400%(급증) / -90%(급감) / +120% |
| 결측값 변경 | 2셀 (종업원수: 결측→45, 95→결측) |
| 타입 변경 | 1셀 (매출액: 850 → "비공개") |
| 안내 | B 전용 컬럼(ESG등급) 비교 제외, 중복 키 처리 방식 |

## 비교 검증용 (2쌍)

표의 **모양**에 따라 무엇을 기준 컬럼으로 잡아야 하는지 보여 주는 짝입니다. 두 쌍 모두 CSV / XLSX 로 제공됩니다.

| 쌍 | 표 모양 | 기준 컬럼 | 비교되는 값 |
|----|---------|-----------|-------------|
| `sample_13_비교_행기준_A_2023` ↔ `_B_2024` | **세로형** — 각 행이 하나의 대상 | `관리번호` (자동 추천) | 그 행의 나머지 **열** 값 |
| `sample_14_비교_열기준_A_2023` ↔ `_B_2024` | **가로형(크로스탭)** — 열 머리글이 비교 대상 | `구분` (자동 추천) | 각 지역 **열**의 값 |

### ⑬ 행 기준 — 세로형 표 (10행 × 7열)

산단별 현황을 2023 ↔ 2024 로 비교합니다. **매출 열의 이름이 서로 달라(`2023년 매출` ↔ `2024년 매출`)
자동 매핑에서 빠지는 것**이 이 샘플의 핵심 학습 포인트입니다.

| 항목 | [비교 시작] 직후 | ③ 열 매핑에서 `2023년 매출 → 2024년 매출` 지정 후 |
|------|------------------|--------------------------------------------------|
| 총 비교 행 | 11 | 11 |
| 동일 / 변경 | 5 / 4 | 3 / 6 |
| 추가 / 삭제 | 1 / 1 (GJ-1011 추가, GJ-1003 삭제) | 1 / 1 |
| 이상 변동 | 1행 | **3행** — 시화 +50%(급증) · 울산 -90%(급감) · 여수 결측 |
| 결측값 변경 | 1셀 (종업원수 1500 → 결측) | 1셀 |
| 타입 변경 | 0셀 | **1셀** (매출 5100 → "비공개") |
| 안내 | `A에만 있는 컬럼: 2023년 매출` / `B에만 있는 컬럼: 2024년 매출` | `이름이 다른 열을 짝지어 비교했습니다` |

> 이름이 다른 열은 **③ 열 매핑** 에서 직접 짝지어야 비교됩니다. 지정 전후를 비교해 보시면
> 왜 이 패널이 필요한지 바로 확인하실 수 있습니다.

### ⑭ 열 기준 — 가로형(크로스탭) 표 (5행 × 6열)

지역이 **열 머리글**로 있고 항목(입주업체수·종업원수 등)이 행에 있는 표입니다.
기준 컬럼을 `구분` 으로 두면 **같은 항목끼리 짝지어 지역 열의 값을 비교**합니다.

| 항목 | 기대 결과 |
|------|-----------|
| 총 비교 행 | 6 (항목 6종) |
| 동일 / 변경 | 1 / 3 |
| 추가 / 삭제 | 1 / 1 (`수출액` 행 추가, `가동률(%)` 행 삭제) |
| 이상 변동 | 3행 — 대구 매출 +50%(급증) 외 |
| 안내 | `A에만 있는 컬럼: 광주` · `B에만 있는 컬럼: 대전` (한쪽에만 있는 지역 열은 비교 제외) |

결과 표는 `상태 | 구분(기준) | 부산 | 서울 | 대구 | 인천 | 태그` 형태로,
지역이 가로로 늘어선 채 각 칸에 `이전 → 이후` 가 표시됩니다.
